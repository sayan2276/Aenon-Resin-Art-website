# Aenon-Resin-Art-website

A bespoke luxury resin art atelier website built with React and Vite. Explore artisanal resin collections, bespoke commissions, custom orders, care guides, and instant docket checkout.

## 🌿 Features

- **Artisanal Home & Showcase**: Curated collections, featured hero showcases, and atelier stories.
- **Interactive Shop**: Filter by collection (Botanical, Ocean Tide, Celestial, Geode), price, and availability.
- **Product Detail & Quick View**: High-resolution galleries, dimensions, resin composition details, and care tips.
- **Custom Commission / Contact**: Bespoke order inquiry builder with live preview and docket integration.
- **Interactive Docket Drawer**: Seamless cart experience with instant order placement and celebratory confetti.

## 🛠️ Tech Stack

- **Framework**: React 19 + Vite
- **Styling**: Vanilla CSS & Design Tokens (Rich botanical & gold atelier aesthetic)
- **Icons**: Lucide-inspired SVG iconography & custom atelier assets
- **Utilities**: `canvas-confetti`

## 🚀 Getting Started

### Prerequisites

- Node.js (v18 or higher recommended)
- npm or pnpm

### Installation

```bash
# Clone the repository
git clone https://github.com/sayan2276/Aenon-Resin-Art-website.git

# Navigate into directory
cd Aenon-Resin-Art-website

# Install dependencies
npm install
```

### Development

```bash
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

### Build for Production

```bash
npm run build
```

The production output will be generated in the `dist` directory.
